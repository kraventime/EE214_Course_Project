# Design of a 4-Digit Decimal Calculator
This project focuses on designing and implementing a fully functional 4-digit decimal calculator on an FPGA.
The system interfaces with two hardware peripherals: a Raw 4-Digit Multiplexed 7-Segment Display
Board and a 4×4 Matrix Keypad. The system hardware architecture processes real-time inputs asyn-
chronously, filters mechanical switch noise, executes signed arithmetic operations, decodes character patterns
via a custom 4-bit driver, and dynamically formats outputs for active visual tracking.
